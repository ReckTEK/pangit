# PanGit README banner

The repository and package READMEs use [pangit-banner.png](pangit-banner.png). The banner pairs the
shared frying-pan mascot with the PanGit wordmark and ReckTEK package scope.

The standalone [pangit-logo.png](pangit-logo.png) remains the source for the documentation site's
logo and favicon. Its generated public copy lives in `packages/pangit-site/public/brand/`.

## Rebranding prompt

The built-in image-generation tool edited the existing banner with this prompt:

```text
Use case: text-localization.
Asset type: PanGit repository README banner.
Input image: the existing banner, used as the edit target.
Replace only the package subtitle with exactly "@recktek/pangit", all lowercase.
Keep the "PanGit" wordmark, all six provider mascots, frying pan, colors, warm cream
background, and composition unchanged. Preserve the wide 3:1 layout at 2304 × 768.
Render the subtitle in the same dark navy monospace style with crisp readable lettering.
The only text must be "PanGit" and "@recktek/pangit". No extra words or icons.
```
