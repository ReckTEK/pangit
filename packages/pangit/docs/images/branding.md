# PanGit branding

Use **PanGit** for the project name and **`@mannsion/pangit`** for the JSR package.

| Asset                                  | Use                                                      |
| -------------------------------------- | -------------------------------------------------------- |
| [pangit-logo.png](pangit-logo.png)     | Transparent P-shaped Git graph mark.                     |
| [pangit-banner.png](pangit-banner.png) | README banner with the mark, wordmark, and package name. |

The identity uses ink navy and warm orange, with an ivory background for the banner. Keep clear
space around the mark and preserve its proportions.

Both assets were created with the built-in imagegen tool. The finished logo was supplied as the
reference for the banner.

## Artwork prompts

<details>
<summary>Logo prompt</summary>

```text
Use case: logo-brand.
Asset type: finished standalone logo mark for PanGit, a TypeScript package for accessing Git hosting REST APIs. This is a new original brand identity.
Primary request: draw a striking, simple P-shaped monogram made from Git branching paths and three circular commit nodes. The stem rises vertically, a rounded branch forms the bowl of the P, and one short branch diverges, all resolved into a coherent compact silhouette. Use strong readable geometry, consistent thick strokes, rounded corners, generous negative space. It must work at tiny icon size.
Style: premium flat graphic design, crisp clean vector-like edges, restrained and confident. Two colors: deep ink navy and vivid warm orange; orange highlights the diverging branch. This is the final logo, not a mockup or a concept sheet.
Composition: one centered symbol only on a square canvas, balanced padding of roughly 15 percent. Request 1024 by 1024 pixels.
Background: genuinely transparent alpha. No baked-in background or checkerboard.
Text: none. Do not include the package name in this standalone mark; the P is a drawn branching symbol, not typeset text.
Avoid: official Git diamond logo, extra symbols, tiny details, mascots, outlines around a square badge, gradients, shadows, 3D, photographic texture, watermarks.
```

</details>

<details>
<summary>Banner prompt</summary>

```text
Use case: logo-brand.
Asset type: finished wide README banner for the TypeScript package PanGit.
Input image: the supplied transparent PanGit logo is the authoritative brand mark. Preserve its recognizable P-shaped Git graph, circular nodes, deep navy strokes, and orange branch. Use it as the left-hand logo in this banner, not as a background or a repeated pattern.
Primary request: compose a polished editorial software-project banner, approximately 1536 by 512 pixels, wide 3:1 format. Warm ivory background, generous clean margins. A balanced horizontal lockup: the supplied mark at left, large beautifully spaced wordmark at right, small package name underneath the wordmark.
Text, verbatim and only these two lines: "PanGit" and "@mannsion/pangit". Capital P and capital G in PanGit. The scope is spelled m-a-n-n-s-i-o-n, with two consecutive n letters. Do not add any tagline or other words.
Typography: strong contemporary geometric sans serif for PanGit, deep navy 'Pan' and orange 'Git'; understated crisp monospaced type in navy for the package name. Every letter must be sharp and correct.
Style: minimal premium graphic design, flat colors and crisp edges matching the supplied logo. Warm ivory, ink navy, vivid orange. The entire logo and all text must fit with ample space above, below, and at both sides.
Avoid: background branches, gradients, texture, 3D, shadows, borders, extra decorations, badges, tiny type, mockups, watermarks, extra text or logos. Deliver one finished banner.
```

</details>
